## 步骤

- [ ] PC 上关闭 VRCFT 及其它占用 25747 的程序
- [ ] FoxyFace 完成标定并开启网络（VRCFT）输出
- [ ] FGB「模块库 → 原生模块」安装 `foxyface-<版本>.zip`
- [ ] 「模块」页把 FoxyFace 设为启动，重启引擎
- [ ] 模块卡片显示活跃，状态页有表情输入

## 观察项

- [ ] 张嘴 → `JawOpen`
- [ ] 微笑 → `MouthCornerPull*` / `MouthCornerSlant*`
- [ ] 吐舌 → `TongueOut`（需 FoxyFace 舌头检测开启）
- [ ] 眨眼 → 睁眼度下降，左右眼独立（`EyeOpenness*`）
- [ ] 眼球左右/上下看 → 注视方向与真实方向一致（**极化重点项**：反了请报告）
- [ ] 遮挡摄像头 >1 秒 → 上游转心跳包，模块不刷新帧但不断流
- [ ] 停止 FoxyFace 发送 → 10 秒内卡片给出「已 N 秒没有数据」
- [ ] 恢复后自动回到活跃

## 与上游对比（可选但有用）

同一台机器上并用 VRCFT + `FoxyFaceVRCFTInterface` 插件，对比同一组表情的参数曲线，
记录明显不一致的形状名；同时确认 `EyeX*/EyeY*` 的符号约定（本模块假设 +X 右、+Y 上，
未经证实）。
